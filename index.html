Политика конфиденциальности — Love_story

Love_story — Telegram-бот для генерации и публикации историй.

Какие данные собираются

Бот сохраняет Telegram ID и username пользователя, а также тексты сгенерированных историй, для работы очереди генерации и истории запросов. Данные не передаются третьим лицам, кроме сервисов, необходимых для работы бота (Google Gemini API, Pollinations.ai, TikTok Content Posting API — по явному запросу пользователя).
