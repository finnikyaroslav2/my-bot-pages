[Название бота] — Telegram-бот для генерации и публикации историй.

Какие данные собираются

Бот сохраняет Telegram ID и username пользователя, а также тексты сгенерированных историй, для работы очереди генерации и истории запросов. Данные не передаются третьим лицам, кроме сервисов, необходимых для работы бота (Google Gemini API — генерация текста, Pollinations.ai — генерация изображений, TikTok Content Posting API — публикация контента по явному запросу пользователя).

Хранение и удаление

Данные хранятся в локальной базе данных бота. Для удаления своих данных свяжитесь с администратором бота.
